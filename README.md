# ATOM-AIO
# ⚛︎ ATOM AIO v1.0.2 ⚛︎

Aplicación de escritorio para Windows.

## Descargar ATOM AIO

ATOM AIO se distribuye mediante el **Release `v1.0.2`** del repositorio.

### Instalación

1. Abre el repositorio oficial de ATOM AIO en GitHub.
2. Ve a la sección **Releases**.
3. Selecciona el release **`v1.0.2`**.
4. En la sección **Assets**, descarga el instalador:

   `ATOM AIO Setup 1.0.2.exe`

5. Ejecuta el instalador.
6. Sigue las instrucciones de instalación.
7. Abre ATOM AIO desde el acceso directo o desde el menú Inicio.

> **Importante:** descarga el instalador únicamente desde los **Assets del Release `v1.0.2` oficial**. No es necesario descargar el código fuente ni ejecutar archivos `.js` directamente.

Al ejecutar el instalador, Windows puede mostrar una advertencia como:

También puede indicar que Microsoft Defender SmartScreen bloqueó el inicio de una aplicación desconocida y mostrar **Editor desconocido**.

Esto puede suceder porque el instalador no cuenta con una firma digital reconocida por Windows o porque SmartScreen todavía no tiene suficiente reputación para el archivo.

### Si descargaste el instalador del Release oficial

Primero verifica que el archivo provenga del **Release `v1.0.2` oficial**.

Si confirmaste su procedencia:

1. Selecciona **Más información**, si aparece.
2. Verifica el nombre de la aplicación.
3. Selecciona **Ejecutar de todas formas**.

Windows permitirá continuar con la instalación.

> **Seguridad:** si el instalador no proviene del Release oficial, no selecciones **Ejecutar de todas formas** hasta verificar su procedencia.

## Activación con Whop

ATOM AIO requiere una **Whop key válida** para iniciar y utilizar la aplicación.

Al abrir ATOM AIO:

1. Introduce tu **Whop key**.
2. La aplicación validará la licencia.
3. Si la key es válida, podrás acceder a ATOM AIO.
4. Si la key no es válida, está expirada o no tiene acceso al producto, la aplicación no podrá continuar normalmente.

### ¿Dónde obtengo la Whop key?

La key se obtiene mediante el sistema de acceso/licenciamiento utilizado para ATOM AIO.

Si ya adquiriste acceso y no encuentras tu key, contacta al administrador o proveedor de tu licencia.

> **No compartas tu Whop key públicamente.** No la publiques en GitHub, capturas de pantalla, Discord, redes sociales u otros sitios públicos.

## Solución de problemas

### Windows bloquea el instalador

Si aparece:

> **Windows protegió su PC**

verifica primero que hayas descargado `ATOM AIO Setup 1.0.2.exe` desde los Assets del **Release `v1.0.2` oficial**.

Si la procedencia es correcta, selecciona **Más información → Ejecutar de todas formas**.

### La aplicación solicita una key

Esto es esperado. ATOM AIO utiliza una **Whop key** para validar el acceso.

Introduce la key proporcionada con tu licencia.

### La Whop key no funciona

Comprueba:

- que la key esté escrita correctamente;
- que no hayas agregado espacios al copiarla;
- que tu licencia siga activa;
- que la key corresponda al acceso de ATOM AIO.

Si el problema continúa, contacta al administrador/proveedor de la licencia.

### La aplicación abre pero muestra un error

Cierra ATOM AIO y vuelve a abrirlo.

Si el problema continúa, proporciona al soporte:

- versión de ATOM AIO;
- mensaje de error;
- pasos que realizaste antes de que apareciera el error.

⚠︎ No compartas tu Whop key ni credenciales de Amazon al reportar el problema. ⚠︎
